# 手机本地主模型

当前实现：首次第二步选择「手机本地运行」或「在线模型」。本地分支下载后点击「用作主模型」，先完成真实本机工具调用测试，通过才保存主模型并进入高级功能邀请。失败或取消不覆盖原有配置。设置 → 模型 → 手机本地模型可重新下载、停止、切换或删除；被主模型或轻量用途使用的文件不能删除。

## 推理与工具调用

复用 APK 内的完整 llama.cpp server（运行文件名为 libjevserver.so），独立本机随机端口、每次随机密钥、禁用代理及重定向，核对 `/props` 的模型路径后才发送对话。无需电脑或外部 Ollama/LM Studio 服务。设置里的这两种服务预设仍只是外部 HTTP 连接，与手机内下载的模型分开。

`LocalChatModel` 实现 `StreamingChatModel`，通过现有 OpenAI 兼容适配器处理文字流、结构化工具调用和工具结果。主模型进入原有 Agent 执行入口，应用访问规则和风险确认继续生效。启用测试必须返回唯一 `get_time` 工具与有效空对象参数，不执行该测试工具；文字描述、错误工具或残缺参数不能通过。

运行时启用 Jinja、关闭 Qwen3 思考，固定 16384 token 上下文和最多 2048 token 输出；关闭 context shift，过长请求应按现有上下文机制压缩或明确报错。模型能力固定为文字及工具，不接受用户设置把它标成视觉模型或扩大运行时上下文。可使用控件树和本地 OCR；纯图像定位及复杂任务质量需另行验证。启用本地模式时轻量用途切为主模型、视觉用途关闭，不自动转云端。

加载阶段 180 秒，健康/身份单请求 5 秒，生成阶段最多 10 分钟；初始化启用测试另有 5 分钟总预算。每次请求结束或取消后关闭原生进程，父 App 退出也联动终止，不后台常驻。主模型、Jev 推理和主模型文件变更共享互斥入口。当前每轮请求都重新加载，避免长期占用内存，也会增加多步骤任务延迟；没有真机数据前不承诺交互速度。

## 高级手机操作

本机推理无需开发者选项；读取/操作其他 App 的高级能力需另行设置。无障碍授权后，可在初始化第三步点击「解锁高级功能」，或从设置首页「解锁高级手机操作」进入，点击「开始自动设置」。程序按已完成状态跳过步骤，协助开启开发者选项、USB 调试、无线调试并打开配对；密码、系统确认及网络授权由用户操作。设置自动化不依赖主模型。详见 [自动设置验收](setup-automation-check.md)。

## 验证边界

本地协议、SSE 工具往返、模型身份检查、取消、超时、下载续传、SHA、配置持久化与本地路由有 JVM 回归。选择模式、启用按钮、取消、删除和高级入口有设备测试源码。编译通过不代表真实手机能成功加载模型；启用时的本机测试用于拦截设备/模板运行失败，不能代表完整多步骤任务能力。目标手机仍需验证首次下载、无网络推理、工具调用、冷启动、内存峰值、热降频和耗电。
