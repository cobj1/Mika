# 任务内按需文字校验

`phone_verify_text` 是单独的只读工具。模型应先用控件树或普通 OCR 读屏，仅在文字不确定或关键字段需要复核时调用；普通 `readVisibleText` 和 `phone_watch` 不运行 Jev。工具不下载模型，不自动开启任何设置，也不按分数判定动作或任务成功。

工具要求 `region: [left, top, right, bottom]`，四条边为全屏归一化 `0..999`，必须有正面积。`text` 可明确给出，最多 1000 字符；省略时在本次截图的区域中运行 OCR。两个识别器给出相同且重叠的文字可作为单个候选，多个不同候选、不同位置的重复文字或空结果均返回说明而不启动评分。可以缩小区域或明确给出要测试的候选后再调用。

Android 端先轻量检查模型和可用内存，再在同一把帧锁下取得文字区域、逻辑几何与生产者时间戳。直接从物理原帧绘制旋转后的文字区域，长边最多 1024，不再先复制整张屏幕。OCR 与 Jev 使用同一份裁剪像素；OCR 坐标按实际向外取整的像素区域映回全屏，避免小框坐标偏移。位图与编码均有边界，OCR 副本等两套识别器结束后释放；取消后跳过候选整理，转换异常也会完成资源收尾。图片和候选不会写入日志或共享目录。

任务通过 `JevController.evaluateAgent` 与手动页面共用推理互斥锁；忙时立即返回，不排队，不更新手动页面的评分。完整性校验结果同步模型就绪状态，避免任务已能评分而设置页仍显示未下载。任务在 OCR 前和权重检查前检测可用内存，实际启动前仍再次检查；页面已有评分缓存命中不增加内存门槛。任务继承取消，停止或用户插话时取消推理并清理原生进程。工具总时限为 7 分钟，覆盖完整性检查、OCR、最多 3 分钟加载和 3 分钟评分；没有提高其他工具的时限。

返回 `uncalibratedScore`、候选及来源、文字区域、原始帧时间戳、`capturedAgoMs`、`newerFrameAvailable` 与耗时。`capturedAgoMs` 表示复制这一帧后经过多久，并非生产者帧的绝对年龄。`ok=true` 只表示得到分数；没有通过阈值、校准概率或任务成功字段。区域也是输入要求的文字范围，不是可点击控件的定位结果。评分后操作前必须重新观察。

端口在读前和返回前检查应用访问权限；虚拟屏被替换、画面不可用或受保护时不返回旧分数。模型缺失、硬件不支持、内存不足、完整性检查失败、候选歧义和超时均有明确错误码，调用方应退回普通读屏或交给用户，不能循环重试安装模型。

验证包含核心工具的只读路由、参数拒绝、取消和总超时、候选冲突与坐标映射、前后访问权限检查，以及真实 Android 位图裁剪测试。端侧评分耗时、准确性和热稳定性仍需有模型的真机测试；不能用这些结构测试推断推理性能。
